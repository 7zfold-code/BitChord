# BitChord Font Edition — Volte Rounded

This edition bundles the user-supplied `VolteRounded.ttf` and adds **Volte Rounded** to **Appearance > Font**. Existing choices are retained. The selection uses the existing AppFont preference and applies to Material typography used by the app and standard lyric rendering. Some explicitly styled text, Android widgets, and Arabic/Persian lyric lines with a Vazirmatn override may retain their own fonts.

## Build on GitHub

Upload this source to your fork, then run **Actions > Build BitChord Font Edition > Run workflow**. Download the dev-debug APK artifact and install it on your Android phone. The `devDebug` variant uses a separate application ID from the release app. Debug signing is not suitable for distribution.

The modified APK has **not** been compiled or device-tested in this environment.
